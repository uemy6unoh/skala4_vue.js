# SKALA Vue.js Hands-on

Vue.js 강의에서 배운 내용을 날씨 애플리케이션에 단계별로 적용했습니다. 각 Hands-on은 이전 단계의 결과를 이어서 확장하는 방식으로 구현했습니다.

## 과제별 폴더와 실행 경로

| 과제 | 폴더 | 실행 경로 | 주요 내용 |
|---|---|---|---|
| Hands-on 1 - MockUp | [1.MockUp](src/components/hands-on/1.MockUp/) | `/hands-on/1` | Vue 기본 문법과 이벤트 적용 |
| Hands-on 2 - Composition | [2.Composition](src/components/hands-on/2.Composition/) | `/hands-on/2` | `computed`, `watch`, `watchEffect` 적용 |
| Hands-on 3 - Component | [3.Component](src/components/hands-on/3.Component/) | `/hands-on/3` | 화면을 역할별 컴포넌트로 분리 |
| Hands-on 4 - Router | [4.Router](src/components/hands-on/4.Router/) | `/` | 주소에 따른 화면 전환 구현 |
| Hands-on 5 - Store | [5.Store](src/components/hands-on/5.Store/) | `/hands-on/5` | Pinia를 이용한 공통 상태 관리 |
| Hands-on 6 - Axios | [6.Axios](src/components/hands-on/6.Axios/) | `/hands-on/6` | Axios를 이용한 실제 날씨 API 연동 |
| Hands-on 7 - UI Library | [7.UI-Library](src/components/hands-on/7.UI-Library/) | `/hands-on/7` | Element Plus UI 컴포넌트 적용 |
| Hands-on 8 - Deployment | [8.Deployment](src/components/hands-on/8.Deployment/) | 최종 배포 주소 | ESLint, 환경 변수, 빌드 및 배포 점검 |

Router 과제의 세부 화면은 `/about`, `/guide`, `/weather/:cityId` 경로에서 확인할 수 있습니다.
