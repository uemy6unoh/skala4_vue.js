# Hands-on 1 - MockUp

## 구현 목표

날씨 데이터를 카드 형태로 반복 출력하면서 `v-for`, `v-if`, 바인딩과 이벤트 처리 등 Vue의 기본 문법이 하나의 화면에서 어떻게 연결되는지 확인했습니다.

## 구현 내용

- 5개 도시를 `v-for`와 `:key`로 반복 출력
- 기온과 미세먼지 상태를 `v-if / v-else-if / v-else`로 구분
- `:value + @input`으로 한글 입력값을 즉시 화면에 반영
- `v-on`의 축약형인 `@click`으로 카드와 버튼의 클릭 이벤트 처리
- 카드에서는 인라인 핸들러로 선택한 도시를 상태바에 표시
- 상세보기에서는 메서드 핸들러를 호출하여 해당 도시의 날씨를 알림창으로 표시
- 상세보기 버튼에 `@click.stop`을 적용하여 부모 카드로 전달되는 버블링 차단
- 날씨 상태에 따라 `:class`로 카드 색상 변경
- `<style scoped>`로 날씨 화면 전용 디자인 구성

## 나의 확장과 의도

기본 데이터에 **습도, 풍속, 미세먼지**를 추가했습니다. 단순히 수치만 늘리기보다 데이터를 사용자가 이해할 수 있는 안내로 바꾸는 것을 목표로 했습니다.

- 맑지만 미세먼지가 나쁘면 마스크 착용 안내
- 풍속이 높으면 야외 활동 주의 안내
- 습도가 높으면 환기 안내
- 미세먼지를 좋음·보통·나쁨으로 구분

디자인은 온도를 가장 크게 강조하는 일반적인 형태 대신 **현재 날씨와 도시를 먼저 인식하는 카드**로 구성했습니다. 날씨별 아이콘을 표시하고 도시명을 크게 강조했으며, 기온은 습도·풍속·미세먼지와 같은 크기의 지표로 배치하여 특정 정보만 지나치게 중심이 되지 않도록 했습니다.

## 배운 점

- 템플릿에서는 `ref`가 자동으로 풀리지만, 스크립트에서는 `.value`가 필요합니다.
- `v-on`은 화면에서 발생한 이벤트와 JavaScript 동작을 연결하며, `@`는 `v-on:`의 축약형입니다.
- 짧은 처리는 인라인 핸들러로 작성하고, 여러 작업이 필요한 경우 스크립트의 메서드 핸들러로 분리할 수 있습니다.
- `v-if / v-else-if` 묶음은 여러 조건이 맞아도 먼저 만족한 하나만 표시합니다.
- 자식 버튼의 클릭이 부모 카드까지 전달될 때 `.stop`으로 버블링을 차단할 수 있습니다.
- `scoped` 스타일을 사용하면 다른 실습 컴포넌트와 CSS가 섞이는 것을 줄일 수 있습니다.
