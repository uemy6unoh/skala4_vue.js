# Hands-on 1 - MockUp

날씨 데이터를 카드 형태로 보여주면서 Vue의 기본 문법을 한 화면에 적용해 본 실습입니다.

## 기본 요구사항

### 배열 렌더링 — `v-for`, `:key`

도시별 날씨 데이터를 `weatherList` 배열에 넣고 `v-for`로 반복 출력했습니다. 카드마다 도시의 고유 `id`를 `:key`로 사용했습니다. 처음에는 반복문이 단순히 HTML을 여러 번 만드는 기능이라고 생각했는데, 데이터가 추가되면 같은 카드가 자동으로 늘어나는 구조라는 점을 확인할 수 있었습니다.

### 조건부 렌더링 — `v-if`

기온이 25도 이상인지에 따라 `따뜻함`과 `선선함`을 나눴습니다. 날씨 아이콘과 미세먼지 등급도 `v-if / v-else-if / v-else`로 구분했습니다. 조건을 여러 개 작성할 때는 위에서 먼저 만족한 내용 하나만 표시된다는 점을 고려해 순서를 정했습니다.

### 입력값 반영 — `:value`, `@input`

검색창의 값은 `searchQuery`와 연결했습니다. 한글을 입력할 때 조합 중인 글자도 화면에 바로 보이게 하려고 `v-model` 대신 `:value`와 `@input`을 사용했습니다. 입력 이벤트에서 받은 `e.target.value`를 `searchQuery`에 넣고, 보간법으로 현재 검색어를 출력했습니다.

### 이벤트 처리 — `@click`, `.stop`

카드를 클릭하면 선택한 도시가 하단 상태바에 표시되도록 했습니다. 상세보기 버튼은 `showDetail` 함수를 호출해 도시명과 날씨를 알림창으로 보여줍니다. 버튼 클릭이 카드 클릭까지 이어지지 않도록 `@click.stop`도 함께 적용했습니다.

## Personal Development

### 날씨 데이터 확장

기본 데이터에 습도, 풍속, 미세먼지를 추가하고 도시도 5개로 늘려봤습니다. `v-for`를 사용하고 있어서 데이터를 추가해도 카드 HTML을 따로 복사할 필요가 없었습니다.

### 수치를 생활 안내로 바꾸기

배운 `v-if`를 기온 구분에만 사용하지 않고 미세먼지, 풍속, 습도를 판단하는 데도 적용했습니다. 미세먼지가 높으면 마스크 안내, 바람이 강하면 야외 활동 주의, 습도가 높으면 환기 안내가 나오도록 만들었습니다.

여러 조건이 동시에 맞을 때 안내가 여러 개 나오는 것보다 중요한 내용 하나가 먼저 보이는 편이 낫다고 생각했습니다. 그래서 미세먼지, 강풍, 습도 순서로 조건을 배치하고 아무 조건에도 해당하지 않을 때만 기본 안내를 표시했습니다.

### 날씨가 먼저 보이는 카드

처음 제공된 화면은 온도 표시가 중심이었지만, 카드에서는 도시명과 현재 날씨가 먼저 보이도록 바꿨습니다. `:class`로 맑음, 흐림, 비 상태에 맞는 색상을 적용하고 `<style scoped>`로 이 화면에서만 스타일이 사용되게 했습니다.

기온, 습도, 풍속, 미세먼지는 같은 크기의 영역에 놓았습니다. 한 가지 수치만 크게 강조하기보다 현재 상태를 한 번에 비교할 수 있게 구성했습니다.

## Trouble Shooting

### 한글 입력이 한 박자 늦게 보이는 문제

처음에는 검색창에 `v-model`을 사용했는데, 한글은 자음과 모음이 조합된 뒤 값이 확정되어 입력 중인 글자가 바로 반영되지 않았습니다. `:value`와 `@input`으로 나눠 작성하고 `e.target.value`를 직접 반영하는 방식으로 바꿨습니다.

### 상세보기와 카드 선택이 같이 실행되는 문제

상세보기 버튼이 카드 안에 있어서 버튼을 누르면 카드의 클릭 이벤트도 같이 실행됐습니다. 클릭 이벤트가 부모 요소로 올라가는 버블링 때문이었고, 버튼에 `.stop`을 붙여 두 동작을 분리했습니다.

### 안내 조건이 하나만 보이는 문제

한 도시에 높은 습도와 강한 바람 조건이 같이 있어도 안내 문구는 하나만 표시됐습니다. `v-if / v-else-if`가 위에서 처음 만족한 조건 하나만 렌더링하기 때문이었습니다. 여러 문구를 모두 띄우기보다 안내의 우선순위를 정하는 방식으로 사용했습니다.

## 정리

처음에는 `v-for`, `v-if`, 바인딩과 이벤트를 각각 따로 외우려고 했습니다. 이번 화면을 만들면서 배열의 데이터가 조건을 거쳐 화면에 표시되고, 사용자의 클릭과 입력이 다시 데이터를 바꾸는 하나의 흐름이라는 점을 확인했습니다.

추가 기능도 새로운 문법을 더 사용하기보다 이번에 배운 문법을 다른 데이터에 적용하는 방식으로 만들어봤습니다.
