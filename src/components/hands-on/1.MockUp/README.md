# Hands-on 1 - MockUp

> Vue의 기본 문법을 하나의 날씨 카드 화면에 연결한 첫 번째 Hands-on입니다.

## 구현 개요

5개 도시의 더미 데이터를 카드 형태로 반복 출력하고, 날씨와 생활 지표에 따라 화면의 정보가 달라지도록 구성했습니다.

도시 검색, 카드 선택, 상세보기까지 연결하여 **데이터 변경 → 조건 판단 → 화면 반영 → 사용자 이벤트 처리**의 흐름을 확인했습니다.

`반응형 데이터 → 반복 렌더링 → 조건부 표시 → 이벤트 처리 → 화면 갱신`

## 배운 내용과 적용

| Vue 문법 및 개념 | 적용 내용 |
|---|---|
| `ref` | 도시 목록, 검색어, 선택된 도시 정보를 반응형 데이터로 관리했습니다. |
| 보간법 `{{ }}` | 도시명, 날씨, 기온, 습도, 풍속, 미세먼지와 사용자 입력값을 화면에 출력했습니다. |
| `v-for` | `weatherList`의 5개 도시를 동일한 날씨 카드 구조로 반복 렌더링했습니다. |
| `:key` | 각 카드에 도시별 고유 `id`를 연결하여 Vue가 목록 항목을 안정적으로 구분하도록 했습니다. |
| `v-if / v-else-if / v-else` | 날씨 아이콘, 기온 상태, 미세먼지 등급과 생활 안내를 조건에 따라 하나씩 표시했습니다. |
| `v-bind`의 축약형 `:` | `:value`로 입력값을 연결하고, `:class`로 날씨 상태에 맞는 카드 스타일을 적용했습니다. |
| `v-on`의 축약형 `@` | `@input`으로 한글 입력 중인 검색어를 즉시 반영하고, `@click`으로 카드 선택과 상세보기 동작을 연결했습니다. |
| 인라인 핸들러 | 카드 클릭처럼 짧은 동작은 템플릿에서 선택된 도시 정보를 바로 변경하도록 작성했습니다. |
| 메서드 핸들러 | 여러 값을 사용하는 상세보기 동작은 `showDetail` 함수로 분리하여 도시명과 날씨 상태를 전달했습니다. |
| 이벤트 수식어 `.stop` | 상세보기 버튼 클릭이 부모 카드의 클릭 이벤트까지 전달되지 않도록 버블링을 차단했습니다. |
| `<style scoped>` | 날씨 카드 스타일이 다른 컴포넌트에 섞이지 않도록 현재 컴포넌트 범위로 제한했습니다. |

## Personal Development

기본 요구사항의 도시명·기온·날씨 데이터에 **습도, 풍속, 미세먼지**를 추가했습니다.

수치를 단순히 나열하는 데서 끝내지 않고, 현재 상태를 빠르게 판단할 수 있는 등급과 생활 안내로 연결했습니다.

| 개선 항목 | 적용 내용 | 화면에서 얻는 효과 |
|---|---|---|
| 생활 지표 확장 | 각 도시에 습도, 풍속, 미세먼지 데이터를 추가했습니다. | 기온만으로 알기 어려운 실제 체감 환경을 함께 확인할 수 있습니다. |
| 미세먼지 등급 | 수치를 `좋음`, `보통`, `나쁨`으로 구분했습니다. | 숫자의 의미를 별도로 해석하지 않아도 현재 수준을 알 수 있습니다. |
| 상황별 안내 | 미세먼지, 강풍, 높은 습도 조건에 따라 마스크 착용이나 환기 안내를 표시했습니다. | 날씨 데이터를 사용자가 바로 실행할 수 있는 정보로 바꿉니다. |
| 복합 조건 처리 | 맑은 날에도 미세먼지가 높으면 마스크 안내가 먼저 나오도록 조건의 우선순위를 정했습니다. | 날씨가 좋다는 이유로 중요한 건강 정보를 놓치지 않게 합니다. |
| 날씨 중심 카드 | 맑음·흐림·비에 맞는 아이콘과 강조 색상을 적용했습니다. | 온도보다 현재 날씨와 도시를 먼저 인식할 수 있습니다. |
| 정보 위계 조정 | 도시명을 크게 표시하고 기온·습도·풍속·미세먼지는 동일한 지표 영역에 배치했습니다. | 특정 수치만 과도하게 강조하지 않고 정보를 균형 있게 비교할 수 있습니다. |
| 클릭 동작 분리 | 카드 선택과 상세보기 버튼의 역할을 나누고 `.stop`을 적용했습니다. | 한 번의 클릭으로 의도하지 않은 두 동작이 함께 실행되는 것을 막습니다. |

조건부 안내에는 `v-if / v-else-if / v-else`를 사용했기 때문에 여러 조건이 동시에 참이어도 **위에서 먼저 만족한 안내 하나만 표시**됩니다.

따라서 건강과 안전에 가까운 조건을 위쪽에 두고, 특별한 주의사항이 없을 때만 기본 안내가 나오도록 순서를 구성했습니다.

## 학습 정리

- `ref`는 Vue가 데이터 변화를 감지하고 화면을 다시 그릴 수 있게 합니다.
- 템플릿에서는 `ref`가 자동으로 풀리지만, 스크립트에서 값을 변경할 때는 `.value`가 필요합니다.
- 계산이 짧으면 인라인 핸들러로 작성하고, 처리할 내용이 많아지면 함수로 분리할 수 있습니다.
- 이벤트 수식어와 `scoped` 스타일을 사용하면 컴포넌트 밖으로 동작이나 디자인이 불필요하게 퍼지는 것을 줄일 수 있습니다.
