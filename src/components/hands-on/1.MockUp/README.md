# Hands-on 1 - MockUp

## 기본 요구사항

### 1. 배열 렌더링 (`v-for`)

배열 렌더링을 배우고 `weatherList`의 도시별 날씨 데이터를 `v-for`로 반복 출력했습니다. 각 카드를 구분할 수 있도록 `:key`에는 도시의 `id`를 연결했습니다.

### 2. 조건부 렌더링 (`v-if`)

조건부 렌더링을 적용해 기온이 25도 이상이면 따뜻함, 25도 미만이면 선선함이 표시되도록 했습니다. 날씨 상태에 따른 아이콘도 `v-if`, `v-else-if`, `v-else`로 구분했습니다.

### 3. 양방향 바인딩 및 한글 처리 (`:value`, `@input`)

한글 조합 중인 검색어도 바로 반영되도록 입력값을 `:value`로 표시하고 `@input`에서 `searchQuery`를 변경했습니다. 입력한 도시명은 검색창 아래에서 확인할 수 있게 했습니다.

### 4. 이벤트 및 수식어

카드의 `@click` 이벤트로 선택한 도시를 상태바에 표시했습니다. 상세보기 버튼에는 `@click.stop`을 사용해 카드 이벤트가 함께 실행되지 않도록 하고 해당 날씨를 알림창으로 표시했습니다.

### 5. 본인만의 데이터 추가

기본 도시 데이터에 습도, 풍속, 미세먼지를 추가했습니다. 추가한 데이터를 카드에 표시하고 조건에 따라 생활 안내가 달라지도록 구성했습니다.

## 개인 추가 사항

### 1. 날씨 데이터 확장

도시별 상태를 더 자세히 비교하기 위해 습도, 풍속, 미세먼지 데이터를 추가하고 도시 수를 5개로 늘렸습니다.

### 2. 생활 안내 문구

날씨 데이터가 단순한 숫자로만 보이지 않도록 미세먼지, 강풍, 습도 조건에 따른 생활 안내를 추가했습니다.

### 3. 날씨별 카드 디자인

맑음, 흐림, 비 상태를 빠르게 구분할 수 있도록 날씨 아이콘과 카드 색상을 다르게 적용했습니다.
